# Retired Requirements

Requirement IDs that are no longer in use (`project-standards` 10.6.1.1). An ID is never reused: when a requirement is cut, or takes a new ID because its primary parent changed, its old ID is listed here with the requirement's name, the date and the reason. Old commits, reviews and checklist entries then never point at the wrong requirement. The requirements check (`tests/test_requirements.py`) fails on any requirement that uses an ID listed here.
